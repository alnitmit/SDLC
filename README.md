- Автор: Михайлов Никита Александрович
- Группа: 450503

## Описание

Учебное Java-приложение с графическим интерфейсом для расчёта коэффициента лени по количеству запланированных и выполненных за день дел. Программа показывает рассчитанный процент, уровень прокрастинации и поясняющее сообщение.
